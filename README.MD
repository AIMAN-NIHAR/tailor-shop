1. WHAT IS THIS?
--------------------------------------------
This is your Tailor Shop Management System. It helps you manage:
- Customers
- Measurements
- Orders
- Delivery dates
- Payments (total, advance, remaining)

It works fully OFFLINE on this computer. No internet is required
to use it. Your data stays safe on this computer only.

یہ آپ کی تیلر شاپ کا سافٹ ویئر ہے۔ یہ گاہک، ناپ، آرڈرز، ڈیلیوری
کی تاریخ اور ادائیگی کا حساب رکھنے میں مدد کرتا ہے۔ یہ انٹرنیٹ
کے بغیر مکمل طور پر کام کرتا ہے۔


--------------------------------------------
2. HOW TO INSTALL / HOW TO OPEN
--------------------------------------------
Step 1: Copy the whole "TailorShop" folder to your Desktop
        (or anywhere you like on this computer).

Step 2: Open the "TailorShop" folder.

Step 3: Double-click on "TailorShop.exe" to start the app.

Step 4: Your web browser will open automatically. This is normal.

Step 5: If Windows shows a blue warning screen ("Windows protected
        your PC"), click "More info", then click "Run anyway".
        This is normal and safe - it only happens the first time.

Step 6: If Windows Firewall asks for permission, click "Allow access".

2۔ فولڈر کھولیں اور "TailorShop.exe" پر ڈبل کلک کریں۔
3۔ آپ کا براؤزر خودبخود کھل جائے گا - یہ نارمل ہے۔
4۔ اگر ونڈوز وارننگ دکھائے تو "More info" پھر "Run anyway" پر کلک کریں۔

4. IMPORTANT - KEEP THE APP WINDOW OPEN
--------------------------------------------
When you open TailorShop.exe, a small black window may appear
behind your browser. DO NOT CLOSE this window while you are
using the app - it is what keeps the app running.

When you are done for the day, you can close the black window
to fully stop the app.

ایپ استعمال کرتے وقت وہ چھوٹی سی کالی ونڈو بند نہ کریں - یہی
ونڈو ایپ کو چلائے رکھتی ہے۔ کام ختم ہونے پر اسے بند کر دیں۔

6. YOUR DATA / BACKUP (VERY IMPORTANT)
--------------------------------------------
All your customers, orders, and payments are saved safely on
THIS computer only.

Please take a backup regularly:
  Sidebar > Settings > Download Backup

This downloads one single file with ALL your data. Save this
file somewhere safe (USB, email to yourself, Google Drive, etc.)
every week, or whenever you add a lot of new data.

If anything ever goes wrong with this computer, this backup
file can be used to restore all your data.

ہفتے میں ایک بار "سیٹنگز" سے بیک اپ ڈاؤن لوڈ کریں اور اسے
کہیں محفوظ جگہ رکھیں (USB، ای میل، گوگل ڈرائیو وغیرہ)۔
